C. Pelacakan lokasi dengan interval adaptif

File: src/hooks/useLocationTracking.ts.

Fungsi getAdaptiveDistanceInterval, sekitar baris 5-15:

function getAdaptiveDistanceInterval(speed: number | null): number {
  if (speed === null || !Number.isFinite(speed) || speed < 1.5) {
    return 8;
  }
  if (speed < 6) {
    return 20;
  }
  return 40;
}

Arti interval:
- Kecepatan tidak diketahui atau di bawah 1.5 m/s: distanceInterval 8 meter.
- Kecepatan 1.5 sampai di bawah 6 m/s: distanceInterval 20 meter.
- Kecepatan 6 m/s atau lebih: distanceInterval 40 meter.

Alur izin dan lokasi awal, sekitar baris 31-48:

const permission = await Location.requestForegroundPermissionsAsync();
if (!permission.granted) {
  setError("Izin lokasi belum diberikan ...");
  return;

const currentLocation = await Location.getCurrentPositionAsync({
  accuracy: Location.Accuracy.Balanced,
});
setLocation(currentLocation);

Pembaruan saat tracking aktif, sekitar baris 68-96:

const nextSubscription = await Location.watchPositionAsync(
  {
    accuracy: Location.Accuracy.Balanced,
    distanceInterval,
    timeInterval: 3000,
  },
  (nextLocation) => {
    setLocation(nextLocation);
    // Interval dihitung kembali dari kecepatan lokasi terbaru.
  },
);

Catatan untuk presentasi:
distanceInterval adalah ambang perpindahan untuk pembaruan lokasi, bukan
jarak pengguna ke laporan. timeInterval diset 3000 ms. Pelacakan memakai
izin foreground (saat aplikasi digunakan), bukan background tracking.

D. Perhitungan jarak menggunakan Haversine

File: src/geo/haversine.ts.

Konstanta dan fungsi utama, sekitar baris 1-27:

const EARTH_RADIUS_METERS = 6_371_000;

export function haversineDistanceMeters(
  first: { latitude: number; longitude: number },
  second: { latitude: number; longitude: number },
): number {
  const latitudeDelta = toRadians(second.latitude - first.latitude);
  const longitudeDelta = toRadians(second.longitude - first.longitude);
  const firstLatitude = toRadians(first.latitude);
  const secondLatitude = toRadians(second.latitude);

  const haversine =
    Math.sin(latitudeDelta / 2) ** 2 +
    Math.cos(firstLatitude) *
      Math.cos(secondLatitude) *
      Math.sin(longitudeDelta / 2) ** 2;

  return 2 * EARTH_RADIUS_METERS *
    Math.atan2(Math.sqrt(haversine), Math.sqrt(1 - haversine));
}

Pada kode sebenarnya, nilai haversine dibatasi maksimum 1 untuk menjaga
stabilitas perhitungan numerik.

Pemakaian jarak:
- App.tsx, sekitar baris 37-45: getReportDistance memanggil
  haversineDistanceMeters untuk membandingkan lokasi pengguna dengan laporan.
- src/geo/haversine.ts, sekitar baris 29-37: formatDistance menampilkan
  hasil dalam meter atau kilometer.

Penjelasan penting:
Haversine menghasilkan jarak garis lurus di permukaan bumi. Hasilnya bukan
jarak perjalanan atau rute jalan.

4. ALUR DEMO SAAT PRESENTASI
============================================================

Persiapan:
1. Jalankan aplikasi di perangkat atau emulator yang mendukung lokasi.
2. Pastikan internet dan layanan lokasi perangkat aktif.
3. Izinkan akses lokasi ketika aplikasi meminta izin.
4. Jika memakai development build Android sendiri, pastikan API key Google
   Maps sudah dikonfigurasi. File .env.example saat ini masih kosong.

Demo:
1. Tampilkan halaman awal dan jelaskan peta serta marker kategori.
2. Pilih kartu laporan dan tunjukkan peta mengarah ke titik tersebut.
3. Tekan tombol lokasi dan jelaskan permintaan izin foreground.
4. Setelah izin diberikan, tunjukkan posisi pengguna pada peta dan jarak
   laporan pada kartu.
5. Tunjukkan status interval lokasi jika terlihat, lalu tekan tombol lokasi
   kembali untuk menghentikan tracking.

6. PERTANYAAN YANG MUNGKIN DITANYAKAN
============================================================

T: Apa itu LBS?
J: Fitur aplikasi yang menggunakan informasi lokasi perangkat untuk
   memberikan fungsi yang relevan dengan posisi pengguna.

T: Mengapa menggunakan Haversine?
J: Untuk menghitung jarak antara dua koordinat geografis dengan
   memperhitungkan bahwa bumi berbentuk mendekati bola.

T: Apakah jarak yang tampil mengikuti jalan?
J: Tidak. Haversine menghitung jarak garis lurus, belum menghitung rute jalan.

T: Mengapa intervalnya adaptif?
J: Agar ambang pembaruan posisi dapat menyesuaikan kecepatan gerak pengguna.
   Interval ini berbeda dari jarak pengguna ke laporan.

T: Apakah laporan berasal dari database?
J: Belum. Laporan saat ini adalah data contoh untuk demonstrasi peta dan
   perhitungan jarak.

T: Apakah aplikasi melacak lokasi di background?
J: Tidak. Implementasi saat ini meminta izin foreground dan tracking aktif
   saat fitur lokasi digunakan di dalam aplikasi.
